# 数码宝贝版放置冒险 PRD v0.1

状态：第一版草稿 · 2026-11-04

## 目标与边界

以 Poke’Catch 的桌面和移动网页为参照，完整复刻可在单机环境运行的界面、操作体验和玩法。玩家能从新建冒险一路玩到已开放的后期单机挑战。数码宝贝版替换角色、图像、命名和进化数据，交互结构、反馈、玩法规则和进度节奏以参照版为准。现有的两路线换皮原型仅供对照，不能作为功能完成标准。

本版排除登录、云存档、好友、玩家交换、市场、全服动态、线上排行榜、好友异步突袭、PVP 和后台管理。只服务这些功能的入口和通知从本地版界面移除。NPC 交换、单人突袭、个人挑战记录等可独立运行的功能保留。共享数据驱动但可以单机运行的内容按参照规则用本地数据计算，具体日历与轮换规则待对照。

## 参照版本与复刻标准

现有证据以已归档的前端构建 `b095b65025` 和作者说明为起点。实现前用可访问版本建立页面和流程对照清单，记录参考日期、桌面与手机截图、入口、点击顺序、前置条件、空态、失败态和结果。原站后续更新另行评估。本表中的单机功能都是首版范围，需逐项确认。遇到未解锁或无法直接观察的功能，标为待取证，取得证据后再定细则。

参照版的导航位置、面板层级、场景构图、信息密度、控件状态、弹窗、动效和移动端交互都纳入验收。保留数码宝贝主题替换及上述联网入口删减。换主题后，玩家仍应能按与参照版相同的顺序找到功能、完成操作并理解结果。

## 功能需求

| 编号 | 范围 | 用户可见要求 |
| --- | --- | --- |
| FR-01 | 标题页与首次游玩 | 复刻标题页、新游戏、玩法帮助和开局选择流程。已有本地档时提供原作对应的继续路径。更新日志保留入口形式，内容使用本项目记录。 |
| FR-02 | 主界面与交互 | 对齐顶栏、状态信息、主场景、导航、日志与详情弹窗。对齐桌面点击、拖拽和移动长按等操作，以及锁定、禁用、提示、关闭和返回行为。原站已有的主题、语言和减少动画入口纳入界面清单。 |
| FR-03 | 探索与自动战斗 | 对齐区域、路线、遭遇、战斗、结算、休整与继续的循环。速度按钮以中文保存页的 ×1／×2／×3 为显示基线，实际倍率和暂停能力待核实。复刻出招、属性克制、体力、经验、等级和失败恢复。昼夜、天气及其他遭遇条件影响对应物种。 |
| FR-04 | 捕获、队伍与仓库 | 对齐捕获条件、概率、道具消耗、捕获反馈、入队与满员入仓。复刻队伍编排、怪兽详情、筛选和排序。队伍调整在原作规定的时点生效。 |
| FR-05 | 成长与图鉴 | 复刻经验、等级、招式、进化和异色等成长及收集机制。首批图鉴收录 Digital Monster Ver.1–5 共 70 条，名录与进化关系以[第一世代图鉴资料](gen1-digimon-reference.md)为准。动画和后续游戏的路线见[扩展参考](evolution-reference.md)。进化交互参照 Poke’Catch，具体触发条件另定。图鉴呈现发现、捕获、异色与区域等状态，按参照核实进化和交换后的登记保留规则。 |
| FR-06 | 地图、黑暗四天王与最终 Boss | 保留地图、区域导航、章节推进和成就。主线挑战依次为钢铁海龙兽、木偶兽、机械邪龙兽、小丑皇，击败四天王后解锁最终 Boss 启示录兽。以首领击败记录作为进度里程碑，承接原作徽章的解锁职责。 |
| FR-07 | 商店、背包与寄养 | 复刻本地货币、商店、物品取得与使用、寄养、孵蛋与进度反馈。涉及玩家市场的功能按范围排除。 |
| FR-08 | 进阶单机玩法 | 对照单人突袭、传说遭遇、战斗塔、地下探索、赌场和 NPC 交换。每项核实解锁、参与条件、失败、重试、结算和奖励。联网排行和成绩提交从相应界面移除。 |
| FR-09 | 本地存档与离线收益 | 在当前浏览器保存伙伴、队伍、图鉴、背包、进度和适用设置。刷新、关闭重开后可继续。按参照规则补算离线收益，显示结算摘要。重复刷新不可重复领取，系统时间回拨时不产生负收益。存储不可用或存档损坏时给出提示，重开覆盖前须确认。 |
| NFR-01 | 静态部署 | 以现有 `site/` 为 Netlify 发布目录。玩法、资源和存档在页面端运行。无需账号或远程游戏 API。调研与 PRD 放在发布目录外。 |

## 主线首领

首领选自《数码宝贝大冒险》。第一世代图鉴的 70 条仍按 Digital Monster Ver.1–5 收录。四天王和启示录兽作为主线专属首领，首版不加入常规捕获池或图鉴完成率分母。[黑暗四天王](https://wikimon.net/Dark_Master) · [启示录兽](https://wikimon.net/Apocalymon_%28Adventure%29)

挑战失败时可重试，胜利后记录里程碑并解锁下一阶段。击败启示录兽后显示主线通关结算，保留本地存档供玩家继续收集。路线、阵容、数值和奖励细则待定。

## 首版验收

先交付可保存的主循环作为中间验收点。用少量第一世代物种和至少一条路线，验证新建、选伙伴、自动战斗、捕获入仓、刷新后继续。此验收点之后再补齐 70 条图鉴、完整主线及其他单机玩法。

遇到参照冲突时，界面以指定保存页或截图为基线，实际行为以同一参照版本实测为准，公开代码用于解释。暂时无法实测的行为标为待核实，独立且已确认的模块可以先做。

1. **界面与操作（FR-01、FR-02）**。用同一组桌面和手机视口，对照标题页、主界面、地图、战斗、队伍、图鉴、商店、寄养及进阶面板。逐项核对布局、导航、触屏操作和状态反馈。记录所有有意保留的差异。
2. **完整单机进度（FR-03 至 FR-08）**。从新档选伙伴开始，完成普通战斗、失败恢复、捕获入仓、换队和进化。依次解锁并击败四天王，核对失败可重试、击败全部四天王前最终 Boss 不可挑战、通关记录刷新后仍保留。覆盖昼夜或天气条件、商店、寄养孵蛋，以及每种确认的后期玩法至少一次成功和一次失败或退出。
3. **本地存档（FR-09）**。验证刷新和关闭重开、离线收益上限、重复打开、时间回拨、损坏档与存储不可用。保留原型存档是否迁移需单独决定。
4. **发布目录（NFR-01）**。只托管 `site/`，验证入口与资源加载。禁用游戏相关外部请求后，仍可开局、战斗、切换面板和保存。

## 待对照与产品决策

- 逐页确认参考版本，补齐隐藏入口、解锁条件、移动端布局、动效和提示文案。旧帖和线上构建可能不同，例如暂停行为。
- 确认内容数量和主题映射。包括区域、物种、属性、首领里程碑对应的商店与路线解锁、高阶挑战，以及进化路线覆盖和触发条件。未确认的公式与数值先记录差异。
- 主线实现前，为每位首领列出挑战前置条件、战后路线、商店解锁、等级限制和奖励。保留普通章节节点的数量待定。
- 图鉴实现前，给 70 条逐一标记取得途径，明确幼年期和进化分支的取得方式。拟区分曾收录与当前持有，以曾收录计算完成率。开局伙伴从首批名录选择。
- 寄养及后期玩法实现前，分别确定产蛋替代机制、单机挑战轮换、塔奖励与 NPC 交换规则。
- 以实际可玩版本核对离线结算上限、队伍变更时点、进化后的图鉴规则和单机挑战的轮换。确定原型存档能否迁移。
- 确定可公开发布的资源清单。现有精灵图、CSS 和背景用于本地对照，公开版需核实许可或替换素材。
